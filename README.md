# RupeeTools

A collection of free financial calculators built for Indian users. The project brings common calculations into one fast, simple web application.

## Calculators

- SIP
- EMI
- GST
- Income tax
- Fixed deposit (FD)
- Public Provident Fund (PPF)

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Recharts
- Tailwind CSS

## Run locally

### Prerequisites

- Node.js 18 or newer
- npm

### Installation

```bash
git clone https://github.com/KishanDavda-IT/RupeeTools.git
cd RupeeTools
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available commands

```bash
npm run dev
npm run build
npm run start
npm run lint
```
